# 小狐狸伊恩 · 安卓悬浮窗桌宠

把网页版的小狐狸伊恩打包成 **安卓悬浮窗桌宠**：小狐狸会飘在手机桌面（其他应用上方也能看到），可拖动、点它展开全部功能（对话、打狐狸、商店、喂食、换装、音效、金币存档）。

工程由 `小狐狸伊恩_安卓/` 整个文件夹构成，通过 **GitHub Actions 云端免费打包**，你电脑**不需要装任何安卓环境**。

---

## 一、准备一个 GitHub 账号（免费）
1. 打开 https://github.com 注册账号（有邮箱就能注册）。

## 二、创建仓库并上传工程
1. 登录后点右上角 **"+" → New repository**，仓库名随便填，比如 `yien-pet`，选 **Public**，**不要**勾选任何初始化选项，点 **Create repository**。
2. 把整个 `小狐狸伊恩_安卓` **文件夹里的内容**（注意：不是文件夹本身，是里面的 `app/`、`build.gradle`、`.github/` 等）上传到仓库根目录：
   - 最简单：在仓库页面点 **"Add file → Upload files"**，把 `小狐狸伊恩_安卓` 文件夹里所有文件拖进去上传，点 **Commit changes**。
   - 或者用 Git 客户端 / 命令行 push，这里不细讲。

> ⚠️ 关键：`小狐狸伊恩_安卓/app/src/main/assets/小狐狸伊恩.html` 这个网页版文件必须一起传上去（悬浮窗展开后加载的就是它）。

## 三、触发云端打包
1. 上传后，GitHub 会自动开始构建（页面顶部会有个橙色/绿色的小圆圈在转）。
2. 点仓库页面的 **"Actions"** 标签，能看到 `Build Android APK` 正在运行。
3. 等 3~8 分钟（第一次会久一点，要下载安卓SDK），变成绿色 **✓** 就成功了。

## 四、下载 APK 并安装到手机
1. 构建成功后，在 Actions 页面点该次运行，最下方 **Artifacts** 里有 `小狐狸伊恩-apk`，点它下载（zip 包，解压出里面的 `.apk`）。
2. 把 apk 发到手机（微信传给自己、或用 USB 拷贝、或手机浏览器登录 GitHub 下载）。
3. 手机点 apk 安装。如果系统提示"未知来源/允许安装"，去 **设置→安全→允许安装未知来源应用** 开启一下。

## 五、第一次使用：开启悬浮窗权限（必做！）
1. 手机上打开 **小狐狸伊恩** 应用，点 **"开启悬浮窗"**。
2. 系统会跳到权限页，**允许"显示在其他应用上层"**（悬浮窗权限）。
3. 返回后应用会自动开始悬浮，**回桌面**就能看到小狐狸飘在屏幕上了。
4. 若没生效，手动去：**手机设置 → 应用 → 小狐狸伊恩 → 悬浮窗 → 允许**。

## 六、使用说明
- **拖动**：按住小狐狸图标，可拖到屏幕任意位置。
- **展开**：点一下小狐狸图标，展开完整功能面板（就是网页版界面）。
- **收起**：点面板顶部的 **"收起 ▼"**，缩回小狐狸图标。
- 桌宠图标、外观如需更换：把 `app/src/main/assets/pet_float.png` 换成你想要的透明PNG（建议128px左右）再重新 push 即可。

---

## 想改安卓版本 / 兼容性
- 工程默认支持 **Android 8.0（API 26）及以上**（绝大多数手机都支持）。
- 如果只要更老的安卓，可把 `app/build.gradle` 里的 `minSdk` 调低。
